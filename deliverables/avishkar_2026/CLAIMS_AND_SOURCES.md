# Claims and sources

Every important claim used on the Avishkar slides and poster. Numbers on the slides, the poster, and `PRESENTER_NOTES.md` match this register.

Recomputed prototype figures were produced on 20 October 2026 by running the project modules `defects.py`, `timetable.py`, and `calendar_plan.py` against the encoded demonstration backlog. The week plan used `build_horizon_plan` from Thursday 24 September 2026 for 7 days, with a 3-second solver limit per call. That run is a simulation. It is not a divisional operating week.

## Claims checked and left out

| Claim in the SIH deck | Why it is not on the Avishkar slides |
| --- | --- |
| “77%” as a single current punctuality figure | The verified Mail/Express figures are 73.62%, 77.12%, and 77.43%, with years. Rounding the latest number to 77% hides the series. |
| R² = 0.98 as model quality | That score is a matched synthetic hold-out. The shifted synthetic score is about 0.28. Putting only 0.98 on a slide would overstate it. |
| “18 tests, pytest, 3 suites” | The suite has grown since that deck. A stale test count is omitted. |
| “11 REST routes” | Not re-counted for this deck. Omitted. |
| “Division-wide there is only 1 BCM, 2 tampers, and 2 tower wagons” | The code caps the model fleet at those numbers. It is not cited as an official divisional inventory. |
| Screenshot confidence of 99/100 | That display maps a solver status. It is not an accuracy claim. |
| GitHub and YouTube links, team id 162238, team name | Identifying, and not required for the research claim. Omitted under the anonymity practice in the Avishkar rules that were reviewed. |
| “Live VDU” as evidence of a deployed railway system | The screen runs on local and demo data. The slides say prototype, not deployment. |
